# Pine Script Examples

This directory contains example Pine Script files demonstrating various concepts and techniques.

## Examples Included

### Basic Examples
- **hello_world.pine** - Basic Pine Script structure
- **price_line.pine** - Simple price plotting example

### Intermediate Examples  
- **multi_timeframe.pine** - Working with multiple timeframes
- **custom_functions.pine** - Creating reusable functions

## How to Use
1. Copy any example to TradingView Pine Editor
2. Study the code structure and comments
3. Modify and experiment with the parameters
4. Use as reference for your own scripts
