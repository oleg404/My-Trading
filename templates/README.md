# Pine Script Templates

This directory contains template files for creating new Pine Script indicators and strategies.

## Basic Indicator Template
Use the indicator template as a starting point for creating custom technical indicators.

## Basic Strategy Template  
Use the strategy template as a starting point for creating trading strategies with entry/exit logic.

## Usage
1. Copy the appropriate template file
2. Rename it to your desired indicator/strategy name
3. Modify the parameters, calculations, and logic as needed
4. Test on TradingView Pine Editor
